کاربرگ‌های تعاملی ریاضی با GitHub Pages و رویکرد Vibe-Coding

میزبانی رایگان وب

سرویس GitHub Pages این امکان را فراهم می‌کند که هر مخزن گیت‌هاب ظرف چند ثانیه به یک وب‌سایت کامپایل‌شده تبدیل شود. در گذشته، ایجاد یک شبیه‌ساز نمودار یا کاربرگ تعاملی نیازمند ماه‌ها یادگیری عمیق زبان JavaScript و فریم‌ورک‌های وب بود. اما امروزه با ظهور پدیده وایب-کدینگ (Vibe-Coding)، دبیر ریاضی می‌تواند شهود آموزشی خود را به صورت توضیحات فارسی یا انگلیسی در مدل‌های هوش مصنوعی (مانند Gemini یا Claude) بنویسد؛ کد کامل و زیبای HTML/CSS/JS درجا آماده می‌شود و دبیر فقط آن را در شاخه main گیت‌هاب قرار می‌دهد!

همان‌گونه که شین پیج (Shane Page) در راهنمای آموزشی خود برای معلمان تاکید کرده است، ساخت کاربرگ‌های تعاملی ریاضی، درک دانش‌آموز از اثر پارامترها بر نمودارها را از حالت حفظ‌کردن فرمول به تجربه مستقیم چشمی تبدیل می‌کند.

انیمیشن‌های ریاضی شگفت‌انگیز با موتور Manim و مخزن teach-math-with-manim

تکنولوژی ۳Blue1Brown

هر دبیر ریاضی که تا به حال ویدیوهای کانال جهانی 3Blue1Brown را تماشا کرده باشد، مجذوب روانی، دقت برداری و انتقال عمیق شهود هندسی و جبری آن شده است. این ویدیوها با موتور پایتونی به نام Manim (Mathematical Animation Engine) ساخته می‌شوند که توسط گرانت ساندرسون طراحی شده است.

شاید بپرسید: آیا یک معلم دبیرستان وقت دارد پایتون پیشرفته یاد بگیرد؟ خوشبختانه پاسخ منفی است! مخزن متن‌باز و ارزشمند Scorpio69t/teach-math-with-manim دقیقاً برای معلمان ریاضی سراسر جهان گردآوری شده است. این مخزن حاوی صدها اسکریپت آماده، موضوعی و تفکیک‌شده برای سرفصل‌های دبیرستان (مشتق، انتگرال، بردارها، قضیه فیثاغورس، ماتریس‌ها و تبدیلات هندسی) است که فقط با تغییر چند عدد آماده رندر می‌شوند.

# صحنه پویانمایی مفهوم مشتق و خط مماس برای دبیرستان
from manim import *

class TangentLineDerivative(Scene):
    def construct(self):
        # ۱. ساخت محورهای مختصات ریاضی
        axes = Axes(x_range=[-1, 5, 1], y_range=[-1, 9, 2], x_length=7, y_length=5)
        curve = axes.plot(lambda x: 0.5 * x**2, color=BLUE)
        curve_label = MathTex("f(x) = \\frac{1}{2}x^2").next_to(curve, UP)

        self.play(Create(axes), Create(curve), Write(curve_label))
        self.wait(1)

        # ۲. متغیر نقطه ثابت و نقطه متحرک (h -> 0)
        t = ValueTracker(2.5) # مقدار اولیه فاصله h
        x0 = 1.5              # نقطه تماس

        dot_fixed = Dot(axes.c2p(x0, 0.5 * x0**2), color=YELLOW)
        dot_moving = always_redraw(lambda: Dot(axes.c2p(x0 + t.get_value(), 0.5 * (x0 + t.get_value())**2), color=RED))
        secant_line = always_redraw(lambda: axes.get_secant_slope_group(
            x = x0, dx = t.get_value(), func = lambda x: 0.5 * x**2,
            dx_line_color=GREEN, dy_line_color=ORANGE, secant_line_color=YELLOW
        ))

        self.play(FadeIn(dot_fixed), FadeIn(dot_moving), Create(secant_line))
        # ۳. پویانمایی میل کردن h به سمت صفر برای تشکیل خط مماس
        self.play(t.animate.set_value(0.01), run_time=4, rate_func=smooth)
        self.wait(2)

چاپ با استانداردهای رسمی

هر معلم ریاضی تجربه تلخ کار با نرم‌افزار مایکروسافت ورد (Word) را چشیده است: با اضافه کردن یک خط یا یک فرمول کسری، تمام چیدمان صفحه، شماره سوالات و شکل‌های هندسی به طرز غیرقابل کنترلی به هم می‌ریزند! راه‌حل علمی و بین‌المللی این معضل، سیستم حروف‌چینی LaTeX (به ویژه بسته پرتوان XePersian برای زبان فارسی) است.

مخزن گیت‌هاب KelvinSHWong/worksheet-generator نمونه‌ای درخشان از کاربرد گیت‌هاب در تولید انبوه کاربرگ‌ها و نمونه‌سوالات امتحانی تصادفی است. با استفاده از قالب‌های آماده این مخزن، معلمان می‌توانند برای هر دانش‌آموز کاربرگی با داده‌های عددی متفاوت اما سطح دشواری یکسان و همراه با کلید پاسخ تشریحی تولید کنند!

مارک‌داون + همفکری همکاران

یکی از جذاب‌ترین کارکردهای گیت‌هاب برای معلمان، استفاده از فایل‌های مارک‌داون (Markdown با پسوند .md) است. مارک‌داون به شما اجازه می‌دهد متنی ساده و تمیز بنویسید که در عرض چند ثانیه به یک سند زیبا با جدول‌ها، چک‌لیست‌ها و فرمول‌های ریاضی رندرشده با لاتک ($\LaTeX$) تبدیل می‌شود.

علاوه بر این، با ابزار GitHub Issues و Pull Requests، معلمان می‌توانند اشکالات تایپی یا روش‌های حل مختلف یک مسئله را مورد بحث قرار دهند. همچنین با نرم‌افزارهای رایگانی مانند Obsidian یا VS Code، تمام یادداشت‌ها و طرح درس‌های معلم به شکل خودکار با مخزن شخصی در گیت‌هاب همگام‌سازی (Sync) می‌شوند.
